# Hotfix Overlay

Apply to any base scenario when an urgent production repair is required.

Mandatory additions:

1. minimize scope to service restoration/risk containment;
2. establish production evidence or reproducible proxy where feasible;
3. record blast radius and rollback/backout before release;
4. require critical-path regression verification;
5. defer only non-critical design/docs with explicit follow-up items;
6. after stabilization, require root-cause/follow-up review if the emergency flow skipped it.

The overlay does not waive requirement conflicts, destructive-operation approvals, or essential verification.
