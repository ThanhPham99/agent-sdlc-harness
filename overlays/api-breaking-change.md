# Breaking Contract Overlay

Apply when an external API, event, schema, protocol, CLI contract, or other consumer-facing interface is intentionally incompatible.

Mandatory additions:

- explicit contract diff;
- consumer inventory/impact;
- migration/deprecation/compatibility strategy;
- G3 `HUMAN` unless an existing approved compatibility policy explicitly authorizes the break;
- provider/consumer contract or integration verification;
- client/frontend integration guidance when applicable;
- release sequencing and communication notes.
