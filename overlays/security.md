# Security Overlay

Apply when a vulnerability, authentication/authorization rule, secret handling, trust boundary, data exposure, or abuse path is involved.

Mandatory additions:

- classify affected asset/data/trust boundary;
- identify plausible abuse/threat path proportional to risk;
- avoid leaking secrets or unnecessary exploit details into durable artifacts;
- include security-focused verification and regression checks;
- require human G3 when confirmed policy demands it or the change materially alters a trust/permission boundary;
- prefer independent review for high-risk findings when feasible.
